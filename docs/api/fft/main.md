# Legacy FFT Analyzer API (`mmpp.fft.main`)

`mmpp.fft.main` contains an older standalone analyzer class (`FFTAnalyzer`) kept for compatibility.

For new code, prefer:

- `result.fft` (`mmpp.fft.core.FFT`),
- `result.fft.modes`,
- `result.fft.dispersion`,
- `result.fft.transmission`.
